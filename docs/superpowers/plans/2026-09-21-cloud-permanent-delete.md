# 顶栏刷新与报告永久删除实施计划

用户要求：刷新移动至 DSA 研究档案右侧并压缩标题区；回收站支持永久删除。

- 顶栏使用紧凑刷新图标与既有 Tooltip，点击重新读取当前工作台数据并显示实际加载反馈；详情页刷新重新获取当前报告。避免定时动画假装网络已完成。
- 回收站显示恢复及永久删除，确认文案明确不可恢复。仅对本人已在回收站的报告生效，不自动清空，也不对正式既有报告进行删除测试。
- 新增 purge_started_at/purged_at：开始删除后禁止恢复并阻止正文／附件读取；服务端清理 Storage 后完成数据库报告删除。失败保留重试入口，完成后从列表移除。保留列表中隐藏、本人可读取的发布防重记录与独立执行／引擎历史，不承诺删除账号所有数据。
- RPC cloud_begin_report_purge(p_user_id,p_task_id) 返回 purged/bucket/object_path；cloud_finish_report_purge(p_user_id,p_task_id) 完成清理，均仅 service_role。身份由 Vercel API 校验 Auth 得到，不接受客户端指定 user_id 或附件路径。
- API DELETE /api/reports，body 仅 report_id；总预算和各请求超时、有界失败、安全错误文案、no-store；不依赖单一执行账户限制，B 可管理本人记录。新增路由与既有服务端布局一致。
- 测试覆盖验证身份、跨用户、未入回收站、正在发布、删除后不可恢复、Storage/DB 失败重试、重复操作、发布不复活、正文及附件不可访问、前端确认取消和最后一行分页、刷新位置和加载状态。先恢复项目，后正式环境增量迁移和部署。
- 同步部署文档与 CHANGELOG；本地相关测试、lint、构建，远端真实恢复删除验收，正式仅非破坏检查。保留外部截图和回滚说明。
