# 每日 Actions 综合分析实施计划

目标：沿用已批准的单用户方案，Actions 独立读取 A 的云端自选股并发布综合报告；本地 Runner 离线不影响日报，网页 Actions 投递保持关闭。

架构：复用严格综合分析、执行记录和原子发布协议，使用独立执行身份与每日幂等标识；扩展现有每日工作流，默认关闭云端模式，保留旧模式。正式部署前先离线测试，再手动 Actions 验收。

- [ ] 审计既有工作流、交易日判定、会话/发布协议及远端分支。
- [ ] 实现单次每日执行入口、不可变自选股快照、幂等与失败处理；覆盖隔离、重复触发、部分完成及非交易日。
- [ ] 在原工作流添加云端模式、必要依赖和受保护配置，不上传密钥或私有日志到公开 artifact。
- [ ] 补充专题文档、环境变量示例和变更日志，执行相关 Python、SQL、工作流与客户端检查。
- [ ] 配置正式 GitHub Secrets、应用新增迁移、发布代码；手动运行并验证 A 可见/B 不可见。
- [ ] 验收后启用交易日定时任务，记录实际结果与剩余限制。

限制：不创建付费资源、不删除历史、不修改 CruxSet；不把 B 变为执行用户。云端模式禁用旧通知以免向外发送非授权消息。日历判断失败不冒充非交易日成功，失败任务不自动重复调用模型。
