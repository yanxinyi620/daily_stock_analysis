# 精简版界面展示优化设计

## 目标

优化 `docs/project-introduction-compact.html` 第 06 章的真实界面展示，让 Web 工作台和提醒中心都拥有足够的阅读宽度，尤其确保提醒中心截图中的关键价位、提醒条件和界面文字清晰可辨。

## 设计

- 保留现有米白、深墨绿和金色的整体风格。
- 将原来的左右不等宽双栏改为上下排列的两个全宽展示区。
- 每个展示区先显示编号、界面名称和一句功能说明，再显示真实图片。
- Web 工作台继续使用现有动图；提醒中心继续使用现有真实截图。
- 图片保持原始比例，不裁剪、不覆盖文字；展示区使用细边框和轻背景与正文分隔。
- 手机和平板保持单列，不产生页面级横向滚动。
- 打印和减少动画模式下，Web 工作台动图继续替换为已有静态示意图。

## 验收

- 第 06 章含两个独立的界面展示区。
- 两个展示区都占正文内容区的完整一行。
- 提醒中心不再使用较窄的右侧栏。
- 标题和功能说明位于图片上方。
- 1440px、736px 和 360px 浏览宽度均无页面级横向溢出。
- 两个真实素材均能离线加载，打印、减少动画和无 JavaScript 模式保持可读。

## 范围

只修改精简版 HTML、对应契约测试和更新日志说明；不修改原完整版、图片文件或产品功能。
