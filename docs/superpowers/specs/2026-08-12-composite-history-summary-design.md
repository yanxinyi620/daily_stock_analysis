# 综合分析历史摘要设计

## 目标

综合分析历史记录沿用首页个股报告的卡片层级与视觉语言，但默认只展示任务摘要，不在首页展开完整 Markdown。用户通过“完整分析报告”抽屉阅读正文。

## 页面结构

- 顶部主卡显示“今日综合分析”、完成时间、整体状态和执行摘要。
- 指标卡显示个股成功/失败数量与大盘复盘状态。
- 运行信息显示股票范围、失败股票以及通知是否在提交时开启。
- 操作栏只保留“重新运行综合分析”和“完整分析报告”。
- 不显示自选、追问 AI、历史趋势、策略点位、股价或关联板块。

## 数据与兼容

摘要读取历史详情的 `details.contextSnapshot`。旧记录缺少字段时显示“未知”或使用报告摘要回退，不解析 Markdown 猜测结构。新记录额外保存 `notification_requested`，它只表示提交时是否开启通知，不宣称投递成功。

## 验证

首页测试覆盖摘要字段、默认不渲染 Markdown 正文、完整报告入口存在，以及单股操作不出现；同时运行 Web lint 和生产构建。
