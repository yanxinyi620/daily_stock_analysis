# 项目介绍精简对比版设计

## 目标

在不修改现有 `docs/project-introduction.html` 的前提下，创建 `docs/project-introduction-compact.html`，供用户与完整版本对比。新版面向产品、技术和非技术混合读者，优先保证五分钟内理解项目价值，完整阅读控制在约 15–20 分钟。

## 设计方向

- 保留暖米白、深墨绿和铜橙配色，视觉继续采用专业研究简报风格。
- 从九章压缩为六章，正文目标减少 30%–40%。
- 每章只回答一个问题，先给摘要，再给必要细节。
- 不复制完整版本的七字段八步台账；改成八个短步骤，每步只保留动作、工具和结果。
- 使用通俗中文；技术名仅作为括注或代码对应名称。

## 六章结构

1. **项目价值**：它替用户完成哪些重复工作；用四段概括流程、8/5/3 三个指标和“能做/不能做”说明定位。
2. **产品能力**：把选股、每日综合分析、单股分析、问股、回测、自选股与提醒合并为一条研究路径。
3. **工作原理**：用八个短步骤解释单股分析如何从代码变成报告。
4. **完整案例**：合并贵州茅台案例数据和最终报告，保留价格、均线、观望/震荡、评分、仓位和关键点位。
5. **为什么可信**：展示五种数据状态以及观望、关键价位、新闻中性和中等把握的来源。
6. **系统与使用**：合并四层系统组成、失败处理、真实产品截图、使用方式和边界。

## 首屏

- 品牌：Daily Stock Analysis。
- 主标题：`从股票代码，到有据可查的分析结论`。
- 副标题：自动完成行情获取、指标计算、新闻检索与数据检查，并根据已有数据生成分析报告。
- 关键词：`自动分析 · 有据可查 · 持续跟踪`。
- 小字覆盖范围：选股、每日分析、单股分析、问股、回测、自选股与提醒。

## 事实与边界

- 使用 2026-08-12 贵州茅台（600519）历史案例。
- 保留 1345.43、MA5 1331.71、MA10 1336.47、MA20 1316.86、压力 1354.01、评分 54、观望、震荡、中等把握。
- 明确新闻搜索结果为空不等于没有风险。
- 明确选股不等于买入，回测不保证未来，系统不是自动交易程序。
- 程序负责取数、计算和标记缺失；模型根据已有资料整理判断；规则程序复核数字、时段和风险表达。

## 交互与可访问性

- 单文件离线 HTML；仅引用现有本地图片。
- JavaScript 只增强阅读进度、目录高亮和入场动画，主内容无需 JavaScript。
- 桌面使用左侧目录；平板和手机使用顶部横向目录。
- 复杂表格仅在自身容器内横向滚动。
- 支持减弱动画和打印；打印时隐藏目录和进度条。

## 验收标准

- 当前完整版本内容和路径不变。
- 新版恰好六个主章节，并包含六项功能协同和八个分析步骤。
- 贵州茅台事实完整且不出现永鼎股份或 600105。
- 使用五种中文优先的数据状态。
- 包含真实 Web 工作台和提醒中心素材。
- 无外部网络资源；桌面、平板和手机无页面级横向溢出。
